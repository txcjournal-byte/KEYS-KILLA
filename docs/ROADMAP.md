# EVOLVE + EVOLVE FX PRO - roadmap (agreed with the owner, 2026-10-04)

UI rule: no foreign product / brand names anywhere in the plugins. Sound / preset names in English.

## EVOLVE (instrument)
Already in: EVOLVE (bubbles, MAP, POCKET, WORLDS, MY TASTE, MATCH), MELODY (9 genres, BPM, CHORDS layer,
AUDIO -> MIDI, LISTEN MIDI + audio, quick sound picker), BREED LAB, FAMILY TREE, MY SOUNDS,
SAMPLER (PADS, FLIPS + MIDI, MELODY tab), FX (SURPRISE FX, STEP FX 2, RACK), MIX LAB (EQ, COMP,
TIME MACHINE, SPACE + ECHO, COACH), EDIT (edited sounds drag / save edited).

Planned:
- SOUND WORLD: a world map made of millions of dots, coloured by region (Africa, Americas, Europe, Asia ...);
  each region has its own instruments / sound character; regions can be connected -> a new hybrid sound.
  Hover = hear, DRAG TO DAW / SAVE.
- MIDI SHRED: drop a loop -> animated shredder turns it into MIDI (uses AUDIO -> MIDI, polyphonic later).
- KEYS label: what the keys play now, one click back to the preset.
- SONG LAB (sampler extension): song map, found sounds shelf, SAMPLE -> SYNTH, FREEZE MOMENT.

## EVOLVE FX PRO (mixer effect)
Already in: MIX LAB, FX, CHAINS (12 + mine + EVOLVE IT), LISTEN.

Planned (1-8 first proposal):
1. LOUD & SAFE: true-peak limiter, LUFS meter, targets STREAMING / SOUNDCLOUD / CLUB
2. UNMASK: instances on tracks share their spectrum, masking found and cut dynamically
3. REFERENCE MATCH: drop a reference track -> tone / loudness / width matched (AMOUNT)
4. DUCK / PUMP: kick detection ducking (whole or lows only), tempo pump with a drawn curve
5. TRACK ROLES for the COACH: 808 / KICK / VOCAL / MELODY / MASTER
6. A/B/C/D snapshots, level-matched compare
7. MULTIBAND squash / saturation, MONO BASS, per-band width, DE-ESS
8. PERFORM PAD (XY) driving several effects, automatable

Plus (owner's list):
- LOOP LAB: tempo grid of rows SLICE / LOOP / ENVELOPE / FX1 / FILTER / FX2, coloured blocks per step, dice per row
- FX WORLD: world map of dots, every country / region = an effect character, connect regions -> a new effect
- DRAW: draw lines / curves / shapes with coloured pens in a key + scale -> a melody (MIDI)
- BOUNCE: balls fall and bounce off lines you draw - every hit plays a note in the key (rate, speed, bounce, pitch, sway)
- ROOM: real-space reverb (our own generated impulse responses) + move the sound around the room / stereo field
- PHONE: phone / old call degradation (bad signal dropouts, tiny speaker, robot speech, crush, distortion)
- SHIFT: pitch / formant / frequency shifting
- ARCADE: retro game-console effect modes with a live game display (many modes / presets)
- EFFECTOR: our Effector Killa engine (Source/plugins/effector) - same functions, EVOLVE FX PRO design
